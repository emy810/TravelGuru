# api/ (not in use)

This Express server comes from the HackYourFuture project template. **The TravelGuru app does not use it.**

- Authentication and user profiles use **Firebase Authentication** and **Firestore**
- Trip packages come from local data in `app/src/data/`
- The wishlist temporarily uses CrudCrud (see [Known Limitations](../README.md#known-limitations))

The folder is kept for reference and may be removed later.

For the project overview, setup and documentation, see the [main README](../README.md).
